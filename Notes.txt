** Working with Colors **

    1. Apply colors on html elements
    => 
        Always Remeber to run this command : npx @tailwindcss/cli -i ./style.css -o ./output.css --watch

        1. @tailwindcss/cli 
        => If @tailwindcss/cli isn't installed globally, npx will use the local version or
            temporarily download and execute it.

        2. -i ./style.css
        => Equivalent to: --input ./style.css, This is the source CSS file 
            that Tailwind will process.

        3. -o ./output.css
        => Output file => Equivalent to: --output ./output.css After compilation, 
            output.css contains all the Tailwind utility classes your project uses.

        4. --watch 
        => Watch mode.
            Instead of compiling once and exiting, Tailwind keeps running and monitors your files for changes. 


    2. Tailwind colors shades are not there for Black and White

    3. The color shade range is from 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950

        if you use 150, 250 etc then it will not work, for that you will have to do customization

    4. Instead of one fixed count, Tailwind “outline utilities” are grouped:

        1. Core outline utilities (main group)

            These control whether an outline appears and its style:

            outline → enables default outline style
            outline-none → removes outline
            outline-dashed
            outline-dotted
            outline-double

            So there are 5 basic outline style utilities.

        2. Outline width utilities

            These control thickness:

            outline-0
            outline-1
            outline-2
            outline-4
            outline-8

            So typically 5 width utilities.

        3. Outline color utilities

            These are generated from your Tailwind color palette:

            outline-red-500
            outline-blue-600
            outline-green-400
            etc.

            👉 There is no fixed number, because Tailwind generates these dynamically from your theme.colors configuration. In a default setup, this is dozens to hundreds of possible classes depending on shades.

        4. Outline offset utilities

            Controls spacing between element and outline:

            outline-offset-0
            outline-offset-1
            outline-offset-2
            outline-offset-4
            outline-offset-8

            So again about 5 standard offset utilities.
        

** Margin and Padding **

  1. Padding vs Margin (core idea)  
  => 
     Padding = inside space

     Tailwind: p-4

        ┌───────────────────────┐
        │   🟦 padding area     |            
        │   ┌───────────────┐   │
        │   │   CONTENT     │   │
        │   └───────────────┘   │
        │                       │
        └───────────────────────┘       

     
     Margin = outside space

     Tailwind: m-4

        (space outside element)

            ┌───────────────┐
            │   CONTENT     │
            └───────────────┘

        ↑ margin space ↑
  
  2. Direction-based spacing : 

    Padding directions : 
    
     A. px-4 (left + right padding)

    ┌───────────────────────┐
    │ ███ CONTENT ███       │
    └───────────────────────┘
     
     B. py-4 (top + bottom padding)

    ┌───────────────────────┐
    │                       │
    │      CONTENT          │
    │                       │
    └───────────────────────┘

     C. pt-4 (padding top only)

     D. pb-4 (padding bottom only)
    

   3. mx-auto (center horizontally)


   4. p-0 → 0px
      p-1 → 4px
      p-2 → 8px
      p-4 → 16px
      p-6 → 24px
      p-8 → 32px 
      .

    5. p-px → 1px
       m-px → 1px

** width min width max width in tailwind css **

  1. Min-width (min-w-*) => Sets the minimum width an element can shrink to.

    Common classes : 
                      min-w-0 → min-width: 0px;
                      min-w-full → min-width: 100%;
                      min-w-min → min-width: min-content;
                      min-w-max → min-width: max-content;
                      min-w-fit → min-width: fit-content;


  2. Max-width (max-w-*) => Controls the maximum width an element can grow to.

    Common classes :
                    max-w-0 → 0px
                    max-w-xs → 20rem (320px)
                    max-w-sm → 24rem (384px)
                    max-w-md → 28rem (448px)
                    max-w-lg → 32rem (512px)
                    max-w-xl → 36rem (576px)
                    max-w-2xl → 42rem
                    max-w-3xl, max-w-4xl, etc.
                    max-w-full → 100%
                    max-w-screen-sm/md/lg/xl/2xl → viewport-based widths


   3. Arbitrary(specifc) values (very important in Tailwind v3+)

      You can define custom sizes using square brackets: 

      Min-width => <div class="min-w-[300px]"></div>

      Max-width => <div class="max-w-[600px]"></div>

      Or percentages => <div class="max-w-[80%]"></div>


** Height, min-height and max-height **

  ** V.Imp ** To use h-full and h-1/2 and percentages for that we have set the parent container as "h-screen"
  
   1. height (fixed height) : This sets an exact height for an element.
                              The element will always try to be exactly that height
                              Content may overflow unless handled (overflow-hidden, overflow-auto)  
    
    Tailwind classes:
                      h-0, h-1, h-2, … (based on spacing scale)
                      h-1/2, h-1/3, h-full, h-screen, etc.  

    Ex :  <div class="bg-purple-300 h-20 max-h-50  overflow-auto"> Hey i am height  </div> 
          ** Means max-height-50 usse jyada height set nahi ho sakti but usse kam set ho sakti hai
        
        
   2. min-height (minimum height) : This sets the smallest height allowed. The element can grow beyond it if content requires.

    Tailwind classes: 
                      min-h-0
                      min-h-full
                      min-h-screen   

    Ex : <div class="mt-2 bg-purple-300 h-20 min-h-50  overflow-auto"> Hey i am height  </div>
            ** Means min-height-50 usse jyada height set ho sakti but usse kam set nahi ho sakti hai


   3. max-height (maximum height) : This sets the largest height allowed. The element can shrink below it,
                                       but not grow beyond it. 
                                    Prevents an element from growing too tall
                                    Often paired with overflow-auto for scrollable sections   
    
    Tailwind classes:
                      max-h-0
                      max-h-24, max-h-64, etc.
                      max-h-screen
                      max-h-full

** Position in Tailwind CSS **

  1. In Tailwind CSS, position utilities map directly to the CSS position property.
     The available classes are: static, relative, absolute, fixed, and sticky.

  2.  | Tailwind Class | CSS Equivalent       | Use Case                                                  |
      | -------------- | -------------------- | --------------------------------------------------------- |
      | `static`       | `position: static`   | Default document flow                                     |
      | `relative`     | `position: relative` | positioned relative to itself                |
      | `absolute`     | `position: absolute` | positioned relative to nearest non-static parent      |
      | `fixed`        | `position: fixed`    | positioned relative to viewport                      |
      | `sticky`       | `position: sticky`   | Behaves like relative until a scroll threshold is reached |


  3.  Position offsets (used with absolute/relative/fixed/sticky)

    These control where the element goes:

        top-0, top-4, top-10
        right-0, left-0, bottom-0
        inset-0 (all sides)
        inset-x-0, inset-y-0


  4. Z-index (layering) 

      Controls stacking order:

          z-0, z-10, z-50
         -z-10 (send behind)
  
  5. What inset actually means in Tailwind

    inset is just a shorthand for setting: 

        top
        right
        bottom
        left   
            
        So:
            inset-0 → top: 0; right: 0; bottom: 0; left: 0;
            inset-x-4 → left: 1rem; right: 1rem;
            inset-y-2 → top: 0.5rem; bottom: 0.5rem;    

     ** Key rule: inset only works when position is NOT static **

        If an element is static (default), top/right/bottom/left are ignored.


** Container Class in Tailwind CSS **

  1. What is container?
  => 
    In Tailwind CSS, the container class is a layout utility that sets a responsive max-width based on breakpoints
    and centers content horizontally.  

  2. What does container do?

    The container class:
        Sets a responsive max-width
        Centers content (when combined with mx-auto)
        Applies different widths at different breakpoints
        Example behavior
        sm → small max width
        md → medium
        lg → larger container
        xl/2xl → expands further

    So it prevents content from stretching full width on large screens.


   3. How does the container utility behave across screen sizes?
   => 
        | Breakpoint | Container Max Width |
        | ---------- | ------------------- |
        | sm         | 640px               |
        | md         | 768px               |
        | lg         | 1024px              |
        | xl         | 1280px              |
        | 2xl        | 1536px              |


** Background classes in Tailwind CSS **

  1. In Tailwind CSS v4, background utilities are part of the broader “background” design system
     that controls background color, image, size, position, repeat, attachment, and gradients using utility-first classes.

  2. Background Classes in Tailwind CSS v4
    
    A) Background Color : Used to set element background color.

        Syntax: bg-{color}-{shade}

        Examples : <div class="bg-blue-500"></div>
                   <div class="bg-gray-100"></div>
                   <div class="bg-red-600"></div>


    B) Background Image : Used to apply images or gradients.

        Syntax: bg-none | bg-gradient-to-* | bg-[url()]

        Examples : <div class="bg-none"></div>
                   <div class="bg-[url('Page.jpg')]"></div>


        ** Gradient utilities ** : <div class="bg-gradient-to-r from-blue-500 to-purple-600"></div>
        
            Direction options: to-r, to-l, to-t, to-b
                            to-tr, to-bl, etc. 

            to-r = gradient goes left → right
            to-l = gradient goes right → left
            to-b = gradient goes top → bottom
            to-t = gradient goes bottom → top


    C)Background Size : Controls how background images scale.

        bg-auto, bg-cover, bg-contain

        Examples : <div class="bg-cover bg-[url('/img.jpg')]"></div>


    D) Background Position

        Controls alignment of background image. 
            bg-center
            bg-top
            bg-bottom
            bg-left
            bg-right
        
        Example: <div class="bg-top bg-[url('/img.jpg')]"></div>

    E) Background Repeat : Controls repetition behavior.

        bg-repeat
        bg-no-repeat
        bg-repeat-x
        bg-repeat-y

    F) Background Attachment : Controls scroll behavior.

        bg-fixed
        bg-local
        bg-scroll

        Examples : <div class="bg-fixed bg-[url('/bg.jpg')]"></div>
    
    G) shadow in CSS : 

        Syntax : box-shadow: x-offset y-offset blur spread color;

        Example : box-shadow: 0 4px 6px rgba(0,0,0,0.1);

      ** Tailwind provides prebuilt shadow utilities so you don’t write CSS manually. **

        Basic shadow scale: shadow-sm
                            shadow
                            shadow-md
                            shadow-lg
                            shadow-xl
                            shadow-2xl
                            shadow-none 

      ** Inner shadow ** : Shadow appears inside the element Used for pressed buttons or input fields

        Example : <div class="shadow-inner p-4"> Inner shadow </div>

      ** Custom shadow (arbitrary value) ** 

        Example : <div class="shadow-[0_10px_20px_rgba(0,0,0,0.25)] p-4"> Custom shadow </div>

** Interactivity with Tailwind CSS **

  1. Interactivity utilities control how users interact with elements => mouse, touch, keyboard, text selection,
     scrolling, resizing, and pointer behavior. They are thin wrappers around native CSS interaction properties.

  2. Common Interactivity Classes : 
    
    | Category       | Utility                          | CSS Generated             |
    | -------------- | -------------------------------- | ------------------------- |
    | Cursor         | `cursor-pointer`                 | `cursor: pointer`         |
    | Cursor         | `cursor-not-allowed`             | `cursor: not-allowed`     |
    | Pointer Events | `pointer-events-none`            | `pointer-events: none`    |
    | Pointer Events | `pointer-events-auto`            | `pointer-events: auto`    |
    | Text Selection | `select-none`                    | `user-select: none`       |
    | Text Selection | `select-all`                     | `user-select: all`        |
    | Scrolling      | `scroll-smooth`                  | `scroll-behavior: smooth` |
    | Scrolling      | `scroll-auto`                    | `scroll-behavior: auto`   |
    | Resize         | `resize`, `resize-x`, `resize-y` | Controls element resizing |


  3. Interview Examples

    1. Disable Clicks on an Element => The element ignores hover, click, and pointer interactions.

        <div class="pointer-events-none">
            Loading...
        </div>

    2. Make a Button Look Clickable : Shows the hand cursor when hovered. In Tailwind v4, buttons don't
                                      automatically get a pointer cursor, so adding cursor-pointer is common when desired.

        <button class="cursor-pointer">
            Submit
        </button>


    3. Prevent Text Selection => Useful for buttons, draggable items, and UI controls.

        <button class="select-none">
            Click Me
        </button>   
    
    4. Smooth Page Scrolling => Enables smooth scrolling when navigating to anchors.

        <html class="scroll-smooth">


    5. :focus : An element is focused when it is selected and ready to receive keyboard input.   

        Examples:  Clicking into an input field.
                   Pressing Tab until a button or input is selected.
                   Programmatically focusing an element with JavaScript.

                   <input class="focus:border-blue-500" />
        
        Key point: Focus remains until the user moves focus somewhere else.


    6. :active : An element is active while it is being pressed.

        Examples:  Holding down the mouse button on a button.
                   Touching and holding a button on a mobile device.

                   <button class="active:scale-95">
                     Submit
                   </button> 

        Key point: Active exists only during the press action.
    

    7. group-hover  
    =>  
        group-hover lets you change the styles of a child element when its parent is hovered.

        Example :  <div class="group p-4 border">
                     <h3 class="text-gray-700 group-hover:text-blue-500">
                        Product Title
                     </h3>
                   </div>

        How it works: Parent has group.
                      Child has group-hover:text-blue-500.
                      When the parent is hovered, the child text turns blue.


** Columns in Tailwind CSS **

  1. In Tailwind CSS v4, the columns-* utilities are used to create multi-column layouts
     using the CSS Multi-column Layout module.

     They are different from CSS Grid and Flexbox because the browser automatically flows content from one column to the next, similar to a newspaper or magazine layout.

  
  2. Available Column Utilities

    | Tailwind Class       | Generated CSS                    | Width                   |
    | -------------------- | -------------------------------- | ----------------------- |
    | `columns-<number>`   | `columns: <number>;`             | Fixed number of columns |
    | `columns-3xs`        | `columns: var(--container-3xs);` | `16rem (256px)`         |
    | `columns-2xs`        | `columns: var(--container-2xs);` | `18rem (288px)`         |
    | `columns-xs`         | `columns: var(--container-xs);`  | `20rem (320px)`         |
    | `columns-sm`         | `columns: var(--container-sm);`  | `24rem (384px)`         |
    | `columns-md`         | `columns: var(--container-md);`  | `28rem (448px)`         |
    | `columns-lg`         | `columns: var(--container-lg);`  | `32rem (512px)`         |
    | `columns-xl`         | `columns: var(--container-xl);`  | `36rem (576px)`         |
    | `columns-2xl`        | `columns: var(--container-2xl);` | `42rem (672px)`         |
    | `columns-3xl`        | `columns: var(--container-3xl);` | `48rem (768px)`         |
    | `columns-4xl`        | `columns: var(--container-4xl);` | `56rem (896px)`         |
    | `columns-5xl`        | `columns: var(--container-5xl);` | `64rem (1024px)`        |
    | `columns-6xl`        | `columns: var(--container-6xl);` | `72rem (1152px)`        |
    | `columns-7xl`        | `columns: var(--container-7xl);` | `80rem (1280px)`        |
    | `columns-auto`       | `columns: auto;`                 | Browser decides         |
    | `columns-(--my-var)` | `columns: var(--my-var);`        | Custom CSS variable     |
    | `columns-[250px]`    | `columns: 250px;`                | Arbitrary value         |
    | `columns-[30rem]`    | `columns: 30rem;`                | Arbitrary value         |

  
  3. Responsive Columns : You can change column count at different breakpoints.

    <div class="columns-1 md:columns-2 lg:columns-4">
        ...
    </div>

    Meaning: Mobile → 1 column
             Medium screens → 2 columns
             Large screens → 4 columns


  4. Column Gap : Space between columns.

    <div class="columns-3 gap-8">
        ...
    </div>

  
  5. Column Span : Used on child elements.

    <div class="columns-3">
        <div class="break-inside-avoid">
            Card Content
        </div>
    </div>

    Useful utilities: break-inside-auto
                      break-inside-avoid
                      break-inside-avoid-page
                      break-inside-avoid-column

    These prevent content from breaking awkwardly across columns.

  6. xample: Masonry-like Layout

    <div class="columns-3 gap-6">
        <img src="1.jpg" class="mb-4 rounded">
        <img src="2.jpg" class="mb-4 rounded">
        <img src="3.jpg" class="mb-4 rounded">
        <img src="4.jpg" class="mb-4 rounded">
    </div>
