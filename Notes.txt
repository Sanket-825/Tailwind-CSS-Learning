** Working with Colors **

    1. Apply colors on html elements
    => 
        Always Remeber to run this command : npx @tailwindcss/cli -i ./style.css -o ./output.css --watch

        1. @tailwindcss/cli 
        => If @tailwindcss/cli isn't installed globally, npx will use the local version or
            temporarily download and execute it.

        2. -i ./style.css
        => Equivalent to: --input ./style.css, This is the source CSS file 
            that Tailwind will process.

        3. -o ./output.css
        => Output file => Equivalent to: --output ./output.css After compilation, 
            output.css contains all the Tailwind utility classes your project uses.

        4. --watch 
        => Watch mode.
            Instead of compiling once and exiting, Tailwind keeps running and monitors your files for changes. 


    2. Tailwind colors shades are not there for Black and White

    3. The color shade range is from 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950

        if you use 150, 250 etc then it will not work, for that you will have to do customization

    4. Instead of one fixed count, Tailwind “outline utilities” are grouped:

        1. Core outline utilities (main group)

            These control whether an outline appears and its style:

            outline → enables default outline style
            outline-none → removes outline
            outline-dashed
            outline-dotted
            outline-double

            So there are 5 basic outline style utilities.

        2. Outline width utilities

            These control thickness:

            outline-0
            outline-1
            outline-2
            outline-4
            outline-8

            So typically 5 width utilities.

        3. Outline color utilities

            These are generated from your Tailwind color palette:

            outline-red-500
            outline-blue-600
            outline-green-400
            etc.

            👉 There is no fixed number, because Tailwind generates these dynamically from your theme.colors configuration. In a default setup, this is dozens to hundreds of possible classes depending on shades.

        4. Outline offset utilities

            Controls spacing between element and outline:

            outline-offset-0
            outline-offset-1
            outline-offset-2
            outline-offset-4
            outline-offset-8

            So again about 5 standard offset utilities.
        

** Margin and Padding **

  1. Padding vs Margin (core idea)  
  => 
     Padding = inside space

     Tailwind: p-4

        ┌───────────────────────┐
        │   🟦 padding area     |            
        │   ┌───────────────┐   │
        │   │   CONTENT     │   │
        │   └───────────────┘   │
        │                       │
        └───────────────────────┘       

     
     Margin = outside space

     Tailwind: m-4

        (space outside element)

            ┌───────────────┐
            │   CONTENT     │
            └───────────────┘

        ↑ margin space ↑
  
  2. Direction-based spacing : 

    Padding directions : 
    
     A. px-4 (left + right padding)

    ┌───────────────────────┐
    │ ███ CONTENT ███       │
    └───────────────────────┘
     
     B. py-4 (top + bottom padding)

    ┌───────────────────────┐
    │                       │
    │      CONTENT          │
    │                       │
    └───────────────────────┘

     C. pt-4 (padding top only)

     D. pb-4 (padding bottom only)
    

   3. mx-auto (center horizontally)

** width min width max width in tailwind css **

  1. Min-width (min-w-*) => Sets the minimum width an element can shrink to.

    Common classes : 
                      min-w-0 → min-width: 0px;
                      min-w-full → min-width: 100%;
                      min-w-min → min-width: min-content;
                      min-w-max → min-width: max-content;
                      min-w-fit → min-width: fit-content;


  2. Max-width (max-w-*) => Controls the maximum width an element can grow to.

    Common classes :
                    max-w-0 → 0px
                    max-w-xs → 20rem (320px)
                    max-w-sm → 24rem (384px)
                    max-w-md → 28rem (448px)
                    max-w-lg → 32rem (512px)
                    max-w-xl → 36rem (576px)
                    max-w-2xl → 42rem
                    max-w-3xl, max-w-4xl, etc.
                    max-w-full → 100%
                    max-w-screen-sm/md/lg/xl/2xl → viewport-based widths


   3. Arbitrary(specifc) values (very important in Tailwind v3+)

      You can define custom sizes using square brackets: 

      Min-width => <div class="min-w-[300px]"></div>

      Max-width => <div class="max-w-[600px]"></div>

      Or percentages => <div class="max-w-[80%]"></div>


** Height, min-height and max-height **

  ** V.Imp ** To use h-full and h-1/2 and percentages for that we have set the parent container as "h-screen"
  
   1. height (fixed height) : This sets an exact height for an element.
                              The element will always try to be exactly that height
                              Content may overflow unless handled (overflow-hidden, overflow-auto)  
    
    Tailwind classes:
                      h-0, h-1, h-2, … (based on spacing scale)
                      h-1/2, h-1/3, h-full, h-screen, etc.  

    Ex :  <div class="bg-purple-300 h-20 max-h-50  overflow-auto"> Hey i am height  </div> 
          ** Means max-height-50 usse jyada height set nahi ho sakti but usse kam set ho sakti hai
        
        
   2. min-height (minimum height) : This sets the smallest height allowed. The element can grow beyond it if content requires.

    Tailwind classes: 
                      min-h-0
                      min-h-full
                      min-h-screen   

    Ex : <div class="mt-2 bg-purple-300 h-20 min-h-50  overflow-auto"> Hey i am height  </div>
            ** Means min-height-50 usse jyada height set ho sakti but usse kam set nahi ho sakti hai


   3. max-height (maximum height) : This sets the largest height allowed. The element can shrink below it,
                                       but not grow beyond it. 
                                    Prevents an element from growing too tall
                                    Often paired with overflow-auto for scrollable sections   
    
    Tailwind classes:
                      max-h-0
                      max-h-24, max-h-64, etc.
                      max-h-screen
                      max-h-full

** Position in Tailwind CSS **

  1. In Tailwind CSS, position utilities map directly to the CSS position property.
     The available classes are: static, relative, absolute, fixed, and sticky.

  2.  | Tailwind Class | CSS Equivalent       | Use Case                                                  |
      | -------------- | -------------------- | --------------------------------------------------------- |
      | `static`       | `position: static`   | Default document flow                                     |
      | `relative`     | `position: relative` | positioned relative to itself                |
      | `absolute`     | `position: absolute` | positioned relative to nearest non-static parent      |
      | `fixed`        | `position: fixed`    | positioned relative to viewport                      |
      | `sticky`       | `position: sticky`   | Behaves like relative until a scroll threshold is reached |


  3.  Position offsets (used with absolute/relative/fixed/sticky)

    These control where the element goes:

        top-0, top-4, top-10
        right-0, left-0, bottom-0
        inset-0 (all sides)
        inset-x-0, inset-y-0


  4. Z-index (layering) 

      Controls stacking order:

          z-0, z-10, z-50
         -z-10 (send behind)
  
  5. What inset actually means in Tailwind

    inset is just a shorthand for setting: 

        top
        right
        bottom
        left   
            
        So:
            inset-0 → top: 0; right: 0; bottom: 0; left: 0;
            inset-x-4 → left: 1rem; right: 1rem;
            inset-y-2 → top: 0.5rem; bottom: 0.5rem;    

     ** Key rule: inset only works when position is NOT static **

        If an element is static (default), top/right/bottom/left are ignored.


** Container Class in Tailwind CSS **

  1. What is container?
  => 
    In Tailwind CSS, the container class is a layout utility that sets a responsive max-width based on breakpoints
    and centers content horizontally.  

  2. What does container do?

    The container class:
        Sets a responsive max-width
        Centers content (when combined with mx-auto)
        Applies different widths at different breakpoints
        Example behavior
        sm → small max width
        md → medium
        lg → larger container
        xl/2xl → expands further

    So it prevents content from stretching full width on large screens.


   3. How does the container utility behave across screen sizes?
   => 
        | Breakpoint | Container Max Width |
        | ---------- | ------------------- |
        | sm         | 640px               |
        | md         | 768px               |
        | lg         | 1024px              |
        | xl         | 1280px              |
        | 2xl        | 1536px              |
